# 병역일터 공개 HTML 확인 기록

확인일: 2026-10-15 (KST). 로그인 없이 HTTPS GET으로 실제 응답을 확인했습니다.

| 용도 | 경로/구조 |
| --- | --- |
| 검색 | `/caisBYIS/search/cygonggogeomsaek.do?menu_id=m_m7_1&pageIndex=1&pageUnit=50` |
| 상세 | `/caisBYIS/search/cygonggogeomsaekView.do?cygonggo_no=공고번호&byjjeopche_cd=업체코드` |
| 목록 행 | `#content table.brd_list_n tbody tr` |
| 상세 링크 | `td.title a[href*='cygonggogeomsaekView.do']` |
| 목록 순서 | `th` 번호, `td` 제목·회사명·마감일·작성일·조회수 |
| 총 건수 | `.brd_top_n .topics`의 `총 게시물 : N건 (현재/전체 페이지)` |
| 상세 본문 | `#content` |
| 상세 데이터 | `table.table_row`, `th[scope=row]` 다음 `td` |
| 비고 | `caption` 텍스트의 공백을 제거한 값이 `비고`인 표 |
| 명시적 마감 | `#content`에 `이미 마감된 채용공고입니다`만 표시되고 나머지 상세는 생략됨 |

검색 필터의 드롭다운은 자바스크립트로 채워지지만 **결과 목록과 상세 데이터는 원래 HTML에 포함**됩니다. 현재 수집에 브라우저 렌더링은 필요하지 않습니다. 실제 검색은 50건 페이지 요청이 반영되는 것을 확인했습니다. 목록 링크의 `;jsessionid=...`와 불필요한 검색 파라미터는 제거하고 두 고유 식별자만 유지합니다.

상세 라벨: `채용공고`, `등록일자`, `업체명`, `업종`, `주소`, `요원형태`, `고용형태`, **`자격요원`(경력)**, `급여조건`, `최종학력`, `담당업무`, `전직자 채용가능`, `현역배정인원`, `현역편입인원`, `보충역배정인원`, `보충역편입인원`, `접수기간`.

확인 표본: 공고번호 `2000001518889`는 정상 상세를, `2000001486889`는 이미 마감된 상세 응답을 반환했습니다. 표본 회사/공고의 값 자체를 테스트에 고정하지 않고 동일한 표 구조를 재현한 합성 입력으로 검사합니다. 실제 수집 데이터·개인 담당자정보·세션 ID는 테스트 파일에 저장하지 않습니다.

선택자/필드 이름은 모두 [`src/collector/selectors.ts`](../src/collector/selectors.ts)에 모았습니다. 구조 변경 시 이 파일과 파서 테스트를 먼저 수정하세요. 수집기는 필수 필드가 빠진 응답을 저장하지 않으므로 사이트 오류 페이지를 정상 공고로 오인하지 않습니다.
